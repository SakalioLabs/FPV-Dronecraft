# ACRO 下坠回拉修正：0.1.1-playtest.2

用户使用手柄和 ACRO 模式，反馈回正并加大油门后仍刹不住下坠。本轮调整针对默认可玩配置与油门指令传递。

## 原因与改动

旧默认 `legacy_heavy_racing_quad` 的最大推重比为 3.35，横滚/俯仰最大角速度约为 188/176 度每秒。新版默认使用已有的 `5inch_agile_candidate`：推重比 4.288，最大角速度 680/620 度每秒，下降气流的推力折损较小。遥控器设置中的角速度倍率仍然有效。

旧手柄路径在客户端将油门每 tick 上升限制为 0.08，从零到满油门需要 13 个 tick，约 0.65 秒；服务器再施加上升系数 0.24 的平滑，最后进入电机集体推力响应。连续平滑增加了回拉失高。

- `ControlInputSmoother.sampleGamepadThrottle` 在 ACRO 下直接传递校准及油门曲线处理后的有限、限幅输入，并同步内部状态，供后续切换模式使用。
- `LegacyPlayableFlightModelAdapter` 在灵敏预设的 ACRO 模式下直接传递油门指令。旧预设和辅助模式保留原服务器平滑。
- 飞行中的电机启动和停转响应保留。适配器新增上锁检查：上锁时清零电机与指令状态，不再接受仍保持在高位的油门或方向杆。低油门解锁条件和控制会话重置仍走原路径。
- 默认预设资源改为 `5inch_agile_candidate`。冻结的旧飞行模型与枚举回退值保持原样，可用于旧基线对照。

这些数值是可玩模型的参数和软件结果，尚未经过实物五寸机标定。

## 回拉测试

新增测试调用实际 `LegacyPlayableFlightModelAdapter.step`，读取模拟后的实体位置及速度。步长为 0.05 秒，开始高度 300 米；回拉起点的垂直速度为 -18 m/s，电机初始集体推力为零。

| 场景 | 回拉后继续失高 | 刹停下坠所需时间 |
| --- | ---: | ---: |
| 回正后满油门 | 4.881 米 | 0.60 秒 |
| 倾斜 20 度，保持姿态 | 5.193 米 | 0.60 秒 |
| 回正，另有 20 m/s 前向速度 | 7.019 米 | 0.85 秒 |
| 倾斜 45 度，保持姿态 | 10.048 米 | 1.20 秒 |
| 先悬停，再切零油门自然下坠到约 -18 m/s，回正拉满 | 4.728 米 | 0.60 秒 |

输入链对照模拟中，旧预设和双重油门平滑的回正场景失高约 13.5 米。实际适配器测试验证了新版回正回拉约 5 米，并验证首步指令达到 1.0、首步电机集体推力为 2.3584，之后到达 4.288；切油门仍有电机停转过程。

自然下降速度上限为 18 m/s；没有将 20/30/40 m/s 人工速度初始化结果称为自然下坠实测。测试不包含玩家反应时间、网络延迟、地面碰撞、硬件油门端点或实际手感。倾角和前向速度仍会增加刹停距离，贴近地面才开始回拉仍可能碰撞。

## 使用与复现

本机使用 PCL 独立版本 `FPV-Agile-20261008`，保留源实例的手柄映射。版本包含 Mod `0.1.1-playtest.2`、Fabric API `0.141.6+1.21.11`、Java 21 及此前已检查的 LWJGL 3.3.6。启动修复安装脚本新增 `-ModVersion` 参数，新建独立实例并复制指定的遥控器配置文件。

进入允许作弊的创造世界后执行 `/fpvdrone spawn`，V 启用遥控器，G 确认输入为 GAMEPAD，油门归零后 R 解锁，M 切换至 ACRO。先留足高度测试切油门下坠、回正及油门回拉。上锁后在 I 设置页检查油门全行程能否达到 0% 和 100%；不能达到时使用已有校准功能。

可用 `/fpvdrone debug playablepreset legacy_heavy_racing_quad` 对照旧预设，用 `/fpvdrone debug playablepreset 5inch_agile_candidate` 切回新版默认。诊断记录使用 `/fpvdiag start` 与 `/fpvdiag stop`。

新增回归覆盖 ACRO 立即油门、辅助模式和模式切换状态、无效输入限幅、冷电机及自然下坠回拉、电机启停响应、旧模式平滑和已有实体切换预设。完整验证记录随交付包提供。

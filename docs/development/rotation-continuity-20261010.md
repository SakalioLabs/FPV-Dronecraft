# ACRO 连续翻转修复（0.1.1-playtest.6）

这版修复俯仰、横滚翻转后方向异常，以及整圈后突然回正。沿用 .5 的敏捷五寸预设、下坠回拉修正、位置与姿态插值、帧时间监测、桨布局缓存和 Sodium 0.8.14。

## 原因与处理

1. 实体曾把机头在水平面的投影方向当成姿态的 yaw。俯仰经过垂直位置时，水平投影会转向 180°，与仍然连续的 pitch 一起传到相机，重建出的朝向与机身不一致。现在同步模型自身的连续 yaw，并保留碰撞位置回写时的模型四元数。
2. 可玩模型的速度转换使用 Minecraft yaw，而姿态快照采用了相反的 yaw 符号。现在统一为 `Ry(-MinecraftYaw) × Rx(pitch) × Rz(roll)`；恢复、传送时使用同一旋转顺序，选择靠近前一姿态的等价角度分支，经过垂直姿态也不会用水平机头朝向代替 yaw。
3. ACRO 原有机体旋转计算在垂直附近混合了水平机头朝向和机身扭转，只返回 pitch、roll，丢失实际产生的 yaw，再用另一段近似耦合补 yaw。自动飞行回归复现了持续正向俯仰时的实际反向旋转。修复使用完整的机体旋转增量，保留同一次旋转得到的三个姿态分量。
4. ACRO 曾在接近或超过一圈后，把残余姿态归零，启动 28 tick 的横滚恢复锁，还会裁剪速度并重置气动记忆。这会造成突然回正和微调失效。现在松杆只减小角速度，保留当前姿态、动量和气动记忆。旧恢复计数器继续保留兼容字段，值固定为 0。

ANGLE、HORIZON 的辅助回正与模式切换继续按原模式工作。整圈结束时，如果角度恰好是 360°，几何姿态自然等同于水平；如果是 330° 或 390°，ACRO 会保留相应倾角，飞行员继续修正。

## 安装与回退

原实例为 `F:/Desktop/.minecraft/versions/FPV/mods`。关闭游戏后，运行交付文件夹中的安装脚本：

```powershell
& './install-rotation-fix.ps1'
```

安装器核对原 .5、Sodium 和 Fabric API 的 SHA-256，先备份 .5，再安装 .6。Sodium、Fabric API、视距、手柄设置和存档保持现状；同一个 FPV Mod 只保留一个版本。备份和安装凭据在实例的 `fpvdrone-rotation-fix-backups/<时间与标识>/`。

需要恢复 .5 时，关闭游戏并传入本次安装生成的凭据：

```powershell
& './rollback-rotation-fix.ps1' -ReceiptPath 'F:/Desktop/.minecraft/versions/FPV/fpvdrone-rotation-fix-backups/<本次目录>/install-receipt.json'
```

回退也会核对文件，不移除已经安装的 Sodium。

## 验证内容

- 单元回归：正反 360°、720°、混合轴、垂直位置、连续姿态恢复、300°/330°/390° 松杆、0.10 小杆量修正、动量和气动记忆。
- 服务端 GameTest：四台无人机分别执行正反俯仰、横滚两周，逐帧比较模型与渲染的前向、上向，并检查持续输入的机体系旋转方向。
- 客户端 GameTest：通过实际实体元数据包执行正反俯仰、横滚 720°，检查插值端点、跨帧连续性和松杆保持；另检查起飞、FPV、模式切换、上锁、设置页、监测导出与传送同步。
- 普通生产客户端：同一 .6 JAR 与原实例的 Fabric API、Sodium 联合加载，在独立测试世界检查相机、模式、监测、保存及重新打开。
- 安装器：安装、重复运行、回退，以及原文件哈希不一致、重复 Mod、API 或 Sodium 被替换的拒绝路径。

三个模块的 1,371 项单元测试已通过（Fabric 610、飞行核心 491、声学核心 270），服务端 10 项 GameTest 已通过。新的连续 ACRO 黄金轨迹采用 v2 文件，旧 v1 保留；两份轨迹的 994 行输入逐行相同，10 个仅使用 ANGLE/HORIZON 的场景输出完全未变。新版适配器与直接模型路线也逐 tick 对照通过。

客户端姿态包、起飞、FPV、模式切换、上锁与性能导出检查已通过。普通生产检查采用与上版相同的 32 视距、12 模拟距离，窗口 1280×720，固定 96 米半径的脚本路线；相机与模式流程、CPU/GPU 监测、保存后重开及无人机身份/模型等持久化检查全部通过，进程正常退出。首次缩短到 8 视距的检查在保存后重新进入 FPV 时等待超时，记录保留在 `build/performance/rotation-production-20261010/`；它没有通过，也未作为交付验证依据。服务端虚拟遥控器测试自行保持飞行区域区块运行，避免无人机飞出夹具区块后停 tick。

交付包的 `verification/` 保存本次报告与服务端测试日志，`SHA256SUMS.json` 核对包内文件。测试使用独立世界和虚拟控制输入；手柄实机手感尚待用户后续游玩验证。

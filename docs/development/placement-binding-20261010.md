# 无人机独立放置、遥控绑定与玩家身体显示

交付版本：`0.1.1-playtest.11`，Minecraft 1.21.11 / Fabric Loader 0.19.3 / Java 21。

无人机与遥控器现在是两个独立物品。创造模式的 FPV Dronecraft 分类中获取“FPV 穿越机”和“FPV 无人机遥控器”；也可使用 `/give @s fpvdrone:drone` 与 `/give @s fpvdrone:drone_controller`。

1. 手持无人机物品，对空旷的方块顶面右键放置。支持半砖的实际顶面高度；空间被占用或没有支撑时不会生成，也不会消耗物品。生存模式成功放置消耗一个，创造模式保留物品。
2. 手持遥控器，按住 Shift 并对准已放置的无人机右键。新机体在绑定前没有主人。遥控器提示和物品说明显示绑定状态及目标 UUID 前八位；以后只控制这架机体。
3. 油门归零、摇杆回中，按 R 解锁。按 B 按 **目视 → FPV → 无人机第三人称 → 目视** 循环切换。手柄用户沿用原有 I 设置与校准。

遥控器空右键仅显示绑定说明。普通右键无人机不会绑定或修复；Shift 右键也不会修复损伤。其他玩家所有或已解锁运转的机体不能绑定。需更换目标时，先上锁，再 Shift 右键新目标；旧机体的输入和遥控会话会结束。主手有遥控器时优先使用主手的绑定，主手未绑定也不会自动改用副手。绑定保存在物品数据中，随正常世界保存保留。

FPV 与无人机第三人称现在能正常渲染留在原地的真实玩家身体。身体保留原版受伤、击退、重力、皮肤和世界中手持物品的显示；无人机继续单独加载和更新远处区块。无人机视角中仍隐藏屏幕前的第一人称手臂和主副手物品，切回目视恢复。玩家身体在镜头视野之外或被地形遮挡时遵循正常渲染。

`/fpvdrone spawn` 与 V 虚拟遥控器继续供开发检查使用。实际手持遥控器时，控制与状态命令优先使用该遥控器绑定的 UUID，不自动认领或选择最近的机体。新增无人机物品显示模型复用原版小贴图；世界中的指定无人机模型、遥控器模型和贴图保持原设计。

## 安装与回退

安装包目录：`F:/Codex-Project/MCFPV/deliverables/placement-binding-20261010`。

退出游戏，在 Windows PowerShell 运行：

```powershell
& 'F:/Codex-Project/MCFPV/deliverables/placement-binding-20261010/install-placement-binding.ps1'
```

安装器核对 `.10`、Fabric API 和 Sodium 的校验值，将原 `.10` 移至实例中的 `fpvdrone-placement-binding-backups`，再安装 `.11`。设置和存档保留，重复执行不会添加重复 Mod。重新启动原来的 FPV 实例，已有机体也需用遥控器 Shift 右键绑定一次。

如需恢复 `.10`，退出游戏后使用安装回执中的备份路径：

```powershell
& 'F:/Codex-Project/MCFPV/deliverables/placement-binding-20261010/rollback-placement-binding.ps1' -ReceiptPath '备份目录/install-receipt.json'
```

1,392 项单元测试通过（Fabric 631、飞行核心 491、声学核心 270），16 项服务端 GameTest 通过；客户端功能测试和安装、重复安装、回滚及异常拦截的六组演练通过。安装演练使用合成的新版本 JAR 检查安装行为，最终生产 JAR 另做校验及客户端运行验证。

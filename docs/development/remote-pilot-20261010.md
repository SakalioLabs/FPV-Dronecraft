# 独立身体与无人机遥控

交付版本：`0.1.1-playtest.9`，Minecraft 1.21.11 / Fabric Loader 0.19.3 / Java 21。

进入 FPV 或无人机第三人称后，玩家身体留在原处。身体继续遵循原版生存规则：重力、碰撞、怪物攻击、受伤与击退仍然有效。切回目视时，回到身体当前的位置；身体如果在遥控期间被推开或掉落，目视位置也会随之改变。

B 的循环保持 **目视 → FPV → 无人机第三人称 → 目视**。目视时，只要遥控仍然有效，无人机附近继续更新，因此可以重新接上远处的同一架无人机。

无人机拥有独立的区块加载和仿真区域，采用当前有效视距与服务器模拟距离。客户端同时保留身体与无人机附近的区块，避免远距离 FPV 导致身体失去碰撞数据。服务端按两个区域的并集发送区块，重叠区域只发送一份，中间的长距离空隙不加载。无人机区域内的实体正常追踪；当前操控目标在新区块等待生成和发送时保留追踪，避免加载过渡导致失联。

死亡、退出游戏、切换维度、无人机卸载或遥控心跳中断会结束会话并释放额外区块加载。加载票据不写入世界的永久强加载列表。该实现不生成虚假玩家；无人机仍是无人机实体，怪物自然生成等明确依赖真实玩家位置的规则保持原版行为。

该版本保留 `.8` 的三视角、指定 Blockbench 模型、贴图、桨叶动画、连续 ACRO 翻滚、油门回拉、位置姿态插值、性能监测与 Sodium。加载两处不同区域会比仅加载玩家区域使用更多内存和服务器时间，建议先保持目前视距进行测试。

## 安装与回退

安装包目录：`F:/Codex-Project/MCFPV/deliverables/remote-pilot-20261010`。

退出游戏，在 Windows PowerShell 运行：

```powershell
& 'F:/Codex-Project/MCFPV/deliverables/remote-pilot-20261010/install-remote-pilot.ps1'
```

安装器核对 `.8`、Fabric API 和 Sodium 的校验值，将原 `.8` 移至实例中的 `fpvdrone-remote-pilot-backups`，再安装 `.9`。设置和存档保留，重复执行不会添加重复 Mod。安装完成后重新启动原来的 FPV 实例。

如需恢复 `.8`，退出游戏，使用安装回执中的备份目录：

```powershell
& 'F:/Codex-Project/MCFPV/deliverables/remote-pilot-20261010/rollback-remote-pilot.ps1' -ReceiptPath '备份目录/install-receipt.json'
```

## 验证与继续测试

交付检查使用一次性世界，覆盖三个模块的 1,389 项单元测试、10 项服务端 GameTest、真实客户端键盘操作流程，以及加载 Sodium 的普通生产客户端检查。独立遥控检查的 17 项结果全部通过，包括原地身体、真实怪物攻击与击退、身体下落、连续移动 640 米、FPV 额外两次跨区块和目视时额外五次跨区块、新区块加载与实体更新、远距离三视角循环和结束会话时的清理。死亡释放远处区块后，测试按原 UUID 从原版实体存储重新载入同一架无人机，并核对临时诊断加载状态已释放。退出保存重进后，无人机的 UUID、所有者、模型和质量保持。截图经过查看后才打包。检查代码在独立诊断模块中，不进入生产 Mod。

详细结果、截图和校验值放在包内 `verification` 与 `SHA256SUMS.json`。本地验证覆盖单人集成服务器；多人服务端的混合 Mod 环境仍需实际联机测试。

游玩时可先记住自己的站立位置，再飞离数百米并按 B 回到目视；身体应留在原处。生存模式中选择安全场地确认受伤、下落与返回目视正常。若出现区块缺失或视角回退，请保留实例的 `logs/latest.log`，并记录视距、模拟距离和当时的视角。
